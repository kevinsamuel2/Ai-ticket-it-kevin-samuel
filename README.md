# AI Ticket It

Plataforma de publicación de eventos y venta de entradas. Trabajo Práctico Individual de **Desarrollo de Software** (UTN FRBA, 2C 2026), desarrollado con apoyo de herramientas de Inteligencia Artificial.

## 📦 Estructura del proyecto

Monorepo administrado con **npm workspaces**:

```
.
├── packages/
│   ├── backend/   # API REST con Node + Express (persistencia en memoria)
│   └── mobile/    # App mobile con React Native (Expo)
├── package.json   # Configuración del monorepo
└── README.md
```

## 🚀 Inicio rápido

```bash
npm install
```

Las instrucciones para levantar cada paquete se completan a medida que se incorporan.
